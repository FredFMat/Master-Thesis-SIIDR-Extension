# Master-Thesis-SIIDR-Extension
Simulation code for the Master's thesis "Agents of Infection: Extending Compartmental Epidemiological Models to Capture LLM-Agent-Driven Malware Propagation" by Frederic-Francois Mattern, Osnabrück University, 2026

| Script | Content | Location in the thesis |
|— —|— —|— —|

| Phase 1 Baseline Appendix.py | Phase 1 feasibility check | Section 4.5.1 |

| Phase 2 Baseline Appendix.py | Phase 2 baseline (Scenario Group 1) | Section 5.1, Figure 3 |

| Phase 2 Bifurcation Appendix.py | Analysis of equilibria | Section 5.2, Figure 4, Appendices B, C.4, E |

| Phase 2 Scenario 2 Appendix.py | Scenario Group 2 (beta_max), statistical tests | Section 5.3, Figure 5, Appendix F |

| Phase 2 Scenario 3 Appendix.py | Scenario Group 3 (t_half x k) | Section 5.4, Figures 6 and 7, Table 3, Appendix D |

| Phase 2 Scenario 4 Appendix.py | Scenario Group 4 (delta), statistical tests | Section 5.5, Figure 8, Appendix F |

| Phase 2 Scenario 5 Appendix.py | Scenario Group 5 (combined scenario) | Section 5.6, Figures 9 and 10 |


## Requirements

Python 3.14 with the packages:

    numpy 
    scipy 
    pandas 
    scikit-posthocs 
    atplotlib

## Running the scripts

Create the folder `Figures_Presentation/Results/` in the directory you run
the scripts from, as this is the location the figures are saved to.
